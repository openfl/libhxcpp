# Tests that Run.hx skips with -D emscripten, one "Test: reason" per line.
# Programs run under node with NODERAWFS, single-threaded, so these are the
# tests that need what that has not: threads, processes, sockets, or the
# desktop GC settings. A new test that needs one of them goes here too, or the
# Emscripten job fails.

ArrayConcurrentString: threads

CppiaArrayAccess: its host is the first --next section, which -D emscripten does not reach
CppiaBreakpoints: threads
CppiaModuleFree: threads
ExitWithBusyWorker: processes and threads
